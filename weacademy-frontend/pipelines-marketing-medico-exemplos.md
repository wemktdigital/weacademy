# 🔗 Pipelines de Marketing Médico - Exemplos Práticos

Este documento contém exemplos de pipelines prontos para usar no Laboratório de IA, combinando os templates de marketing médico criados.

## 📋 Pipeline 1: Criação Completa de Conteúdo para Redes Sociais

**Objetivo:** Criar post completo otimizado para redes sociais com validação de compliance.

**Etapas:**
1. **Criador de Postagens Sociais Médicas** - Cria o conteúdo inicial
2. **Auditor de Compliance Médico** - Valida conformidade com ANVISA e CFM
3. **Especialista em SEO Médico** - Otimiza para busca (se for para blog/linkedin)

**Quando usar:** Ao criar posts para Instagram, LinkedIn ou Facebook que precisam ser publicados imediatamente com segurança.

---

## 📋 Pipeline 2: Artigo de Blog Completo e Otimizado

**Objetivo:** Criar artigo completo para blog com otimização SEO e compliance.

**Etapas:**
1. **Escritor de Artigos Médicos para Blog** - Escreve o artigo completo
2. **Especialista em SEO Médico** - Otimiza SEO e estrutura
3. **Auditor de Compliance Médico** - Valida compliance antes de publicar

**Quando usar:** Para criar artigos educativos de blog que atraem pacientes via busca orgânica.

---

## 📋 Pipeline 3: Campanha de Marketing Completa

**Objetivo:** Planejar e criar todos os materiais de uma campanha completa.

**Etapas:**
1. **Planejador de Campanhas Médicas** - Define estratégia e objetivos
2. **Gerador de Copy para Anúncios Médicos** - Cria textos para anúncios
3. **Criador de Postagens Sociais Médicas** - Cria posts orgânicos
4. **Auditor de Compliance Médico** - Valida tudo antes de publicar

**Quando usar:** Ao lançar uma nova campanha de marketing ou promoção de serviço.

---

## 📋 Pipeline 4: Newsletter Completa para Pacientes

**Objetivo:** Criar newsletter informativa e engajadora.

**Etapas:**
1. **Desenvolvedor de Materiais para Pacientes** - Cria conteúdo educativo
2. **Criador de Newsletter Médica** - Estrutura a newsletter
3. **Gerador de Perguntas Frequentes Médicas** - Adiciona FAQ relevante

**Quando usar:** Para enviar newsletters mensais ou sazonais para base de pacientes.

---

## 📋 Pipeline 5: Vídeo Educativo Completo

**Objetivo:** Criar roteiro e materiais de apoio para vídeo educativo.

**Etapas:**
1. **Desenvolvedor de Materiais para Pacientes** - Desenvolve o conteúdo base
2. **Criador de Vídeo Scripts Médicos** - Cria roteiro do vídeo
3. **Criador de Infográficos Médicos** - Sugere elementos visuais para o vídeo

**Quando usar:** Ao criar vídeos educativos para YouTube, Instagram Reels ou TikTok.

---

## 📋 Pipeline 6: Análise e Otimização de Performance

**Objetivo:** Analisar campanha e gerar melhorias automaticamente.

**Etapas:**
1. **Analisador de Performance de Marketing Médico** - Analisa métricas
2. **Planejador de Campanhas Médicas** - Cria estratégia otimizada
3. **Gerador de Copy para Anúncios Médicos** - Gera novos textos otimizados

**Quando usar:** Mensalmente ou após campanhas importantes para otimizar continuamente.

---

## 📋 Pipeline 7: Landing Page/Anúncio com Compliance

**Objetivo:** Criar landing page ou anúncio completo e validado.

**Etapas:**
1. **Gerador de Copy para Anúncios Médicos** - Cria headlines e copy
2. **Desenvolvedor de Materiais para Pacientes** - Desenvolve conteúdo educativo
3. **Auditor de Compliance Médico** - Valida antes de publicar

**Quando usar:** Para lançar novos serviços ou tratamentos com materiais publicitários.

---

## 📋 Pipeline 8: Conteúdo Multiplataforma

**Objetivo:** Criar conteúdo que funciona em várias plataformas.

**Etapas:**
1. **Desenvolvedor de Materiais para Pacientes** - Desenvolve conteúdo base
2. **Criador de Postagens Sociais Médicas** - Adapta para Instagram/Facebook
3. **Criador de Vídeo Scripts Médicos** - Cria versão para vídeo
4. **Especialista em SEO Médico** - Otimiza versão para blog

**Quando usar:** Para maximizar alcance criando múltiplas versões do mesmo conteúdo.

---

## 🚀 Como Criar um Pipeline no Sistema

### Passo a Passo:

1. **Acesse:** `/ai-lab/admin/pipelines`
2. **Clique em:** "+ Novo Pipeline"
3. **Preencha:**
   - Nome: ex. "Criação Completa de Post Social"
   - Descrição: "Cria post otimizado e valida compliance"
4. **Adicione etapas** (clique em "+ Adicionar Etapa"):
   - Etapa 1: Selecione agente "Criador de Postagens Sociais Médicas"
   - Etapa 2: Selecione agente "Auditor de Compliance Médico"
   - Etapa 3: Selecione agente "Especialista em SEO Médico" (opcional)
5. **Salve** o pipeline

### ⚠️ Importante:

- **Primeiro, crie os agentes** a partir dos templates
- Os agentes precisam estar **ativos** para aparecerem na lista ao criar pipeline
- A ordem das etapas importa - o output de uma vai como input da próxima

---

## 💡 Dicas de Uso

1. **Teste cada pipeline** com uma entrada simples primeiro
2. **Revise o output** de cada etapa antes de usar em produção
3. **Customize os prompts** dos agentes conforme sua necessidade específica
4. **Combine pipelines** - use output de um pipeline como input de outro

---

## 🎯 Pipeline Recomendado para Começar

**"Pipeline 1: Criação Completa de Post Social"** é o mais simples e útil para começar. Ele garante que todo conteúdo criado já está validado para publicação.
